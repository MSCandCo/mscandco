## 🏗️ Technical Architecture

### Files Structure

```
lib/apollo/
├── brain.js                    (4,606 lines, 146KB) - Main Apollo brain
└── infinite-brain.js           (380 lines, 16KB)   - Infinite tool generator
```

### Class: InfiniteToolGenerator

Located in `lib/apollo/infinite-brain.js`

#### Key Methods:

**1. generateTool(category, subcategory, capability, userContext)**
- Generates tool definition using AI
- Caches generated tools for performance
- Returns tool specification with name, description, capabilities, output format

**2. executeTool(category, subcategory, capability, args, userId, memory)**
- Gets or generates tool definition
- Executes using AI with full user context
- Returns comprehensive results with analysis, insights, recommendations, predictions, actions

**3. recommendTools(userContext, limit = 10)**
- AI-powered tool recommendations
- Analyzes user context and goals
- Returns top recommended tools with reasons and expected impact

**4. getAvailableCategories()**
- Returns all 10 major categories

**5. getSubcategories(category)**
- Returns subcategories for a category

**6. getCapabilities(category, subcategory)**
- Returns all capabilities for a subcategory

**7. getTotalPossibleTools()**
- Calculates total possible tool combinations (100,000+)

### Integration with Main Brain

**1. Import**
```javascript
import infiniteToolGenerator from './infinite-brain.js';
```

**2. Tool Definition in APOLLO_TOOLS**
```javascript
{
  type: "function",
  function: {
    name: "use_infinite_tool",
    description: "INFINITE GENIUS: Access to 100,000+ dynamically generated tools...",
    parameters: { ... }
  }
}
```

**3. Execution Routing**
```javascript
case 'use_infinite_tool':
  return await useInfiniteTool(args, userId, memory);
```

**4. useInfiniteTool() Function**
- Handles 4 actions: execute_tool, recommend_tools, list_categories, discover_capabilities
- Interfaces with infiniteToolGenerator
- Returns structured results
