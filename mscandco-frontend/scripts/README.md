# Scripts Directory

This directory contains various utility scripts organized by purpose.

## Directory Structure

- **`gmail/`** - Gmail automation scripts (moved to parent scripts/gmail/)
- **`screenshots/`** - Screenshot and capture scripts
  - `capture-*.js` - Page capture utilities
- **`python/`** - Python utility scripts
  - `create_presentation.py` - Presentation generation
- **`mcp/`** - MCP server scripts
  - `mcp-server.js` - Main MCP server
  - `mcp-server-ultimate.js` - Enhanced MCP server
- **`instrumentation/`** - Application instrumentation
  - `instrumentation.ts` - Main instrumentation
  - `instrumentation-client.ts` - Client-side instrumentation
- **`archive/`** - Archived/legacy scripts

## Usage

Scripts are organized by their purpose. See individual directories for specific usage instructions.
