## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Database**: Supabase (PostgreSQL)
- **Auth**: Supabase Auth
- **Payments**: Revolut, Stripe
- **AI**: OpenAI GPT-4
- **Analytics**: PostHog
- **Error Tracking**: Sentry
- **Hosting**: Vercel
- **Email**: Supabase (Resend)
